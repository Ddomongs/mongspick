1. 수집하는 정보 (Information We Collect)

MongsPick Uploader("본 도구")는 운영자 본인의 소셜 미디어 계정에 영상을 업로드하기 위한 개인용 도구로, 운영자 본인의 계정 인증 토큰과 업로드할 영상·설명 텍스트만을 처리합니다. 제3자의 개인정보를 수집·저장·판매하지 않습니다.

MongsPick Uploader ("the Tool") is a personal tool for uploading videos to the operator's own social media accounts. It processes only the operator's own account access tokens and the videos/captions to be uploaded. It does not collect, store, or sell any third-party personal information.

2. 정보의 저장 (Storage)

인증 토큰은 운영자의 로컬 컴퓨터에만 저장되며 외부 서버로 전송되지 않습니다.

Access tokens are stored only on the operator's local computer and are never transmitted to any external server.

3. 제3자 제공 (Sharing)

업로드 대상 플랫폼(TikTok 등)의 공식 API 호출 외에는 어떤 정보도 제3자에게 제공하지 않습니다.

No information is shared with third parties except through official API calls to the target platforms (such as TikTok).
